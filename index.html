Delivery

Choose the output your production needs

Browser source

OBS, vMix, Wirecast

  1. Open Settings → Output Setup.
  2. Copy the Output URL into a browser source.
  3. Match its resolution to the selected output size.
  4. Use Transparent for alpha, or select a chroma color to key downstream.
ATEM PNG

Still-image workflow

  1. Choose the ATEM PNG Export tab.
  2. Include the current session and use the premultiplied PNG URL for production.
  3. Use Regenerate when an immediate refresh is required.
  4. Compare straight and premultiplied variants if edges look different.

Ticker is not included in ATEM PNG export.

Controls are not syncing

Confirm every device uses the same session ID and shows an active WebSocket connection. Reload the page after restoring the network.

Output does not match the preview

Check PGM, not only PVW. Confirm the active mode and Overlay Style, then take the corrected preview to air.

ATEM image looks different

Choose Regenerate, then compare the straight and premultiplied PNG variants. ATEM production normally uses premultiplied alpha.

A saved setting is missing

Confirm the session ID, connection status, and automatic-save confirmation. Presets and settings belong to the session in which they were saved.
